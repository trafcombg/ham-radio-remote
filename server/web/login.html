Admin вход — HAM Radio Remote

PostgreSQL не е конфигуриран

Admin панелът (и логването на сесии/предавания) изисква PostgreSQL. Без него сървърът работи с радиата от config.json, но без този панел.

  1. Инсталирай PostgreSQL (ако още нямаш): postgresql.org/download
  2. Създай база: 
    createdb -U postgres hamradio
    (или през pgAdmin, или psql -U postgres -c "CREATE DATABASE hamradio;")
  3. Отвори config.json до HAM-Radio-Server.exe и задай:
    "db": { "dsn": "postgresql://postgres:ТВОЯТА_ПАРОЛА@localhost:5432/hamradio" }
    Формат: postgresql://потребител:парола@host:порт/база
  4. Рестартирай сървъра. Таблиците се създават автоматично — после тази страница ще те прати към /setup за първия admin.
